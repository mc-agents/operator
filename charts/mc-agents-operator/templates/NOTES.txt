{{ include "mc-agents-operator.fullname" . }} is watching {{ if .Values.watchNamespace }}namespace {{ .Values.watchNamespace }}{{ else }}every namespace{{ end }}.

Create a bot:

  kubectl apply -n {{ .Release.Namespace }} -f - <<'EOF'
  apiVersion: mc-agents.dev/v1alpha1
  kind: MinecraftBot
  metadata:
    name: scout
  spec:
    kind: mineflayer
    minecraftVersion: "26.1.2"
    server:
      host: mc-mcp-server.{{ .Release.Namespace }}.svc
      port: 8765
  EOF

Watch it come up:

  kubectl get minecraftbots -n {{ .Release.Namespace }} -w

Scale a pool instead of creating bots one by one:

  kubectl scale minecraftbotpool/scouts -n {{ .Release.Namespace }} --replicas=8

The operator is not on the data path. Bots dial {{ .Values.bots.registry }}-built images at the
MCP server address in their own spec; LINK in `kubectl get minecraftbots` is the pod's readiness,
which the bot turns green once its hello has been accepted.
